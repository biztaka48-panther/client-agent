# サンプラスワンサイト移行メモ（作業用）

本ドキュメントは、現行公式サイト（https://sunplusone.com/）から本プロジェクト（`sunplusone-site/`）へコンテンツを引っ越しする際の観点整理です。旧URL の実値は環境ごとに異なるため、**「旧URL」列は手作業で埋めてください**。

## 新サイトの主要パス

| 区分 | パス |
|------|------|
| トップ | `/` |
| お知らせ | `/news` |
| 事業内容一覧 | `/services` |
| 事業内容詳細 | `/services/traffic` ほか `data/site.ts` の `slug` |
| 警備料金 | `/fees` |
| 採用情報 | `/recruit` |
| 事業所紹介 | `/offices` |
| 会社案内 | `/company`（アンカー `#track` 等） |
| お問い合わせ | `/contact` |
| 移行マップ（画面） | `/migration` |

## コンテンツ検証リスト

1. **会社基本情報**: 本社住所・TEL/FAX は `data/site.ts` の `siteMeta` に集約。変更時は一括反映。
2. **新着・ブログ**: タイトル・日付はトップ掲載分を転記済み。本文・画像は旧管理画面からエクスポート。
3. **料金**: PDF / 表の再掲載と法務確認。フォームとの導線を `/fees` と `/contact` で両立。
4. **採用**: メニューにあった下層（スタッフ紹介等）を個別 URL に分割するか、`/recruit` 内アンカーにまとめるかを決定。
5. **事業所**: 住所・地図は各旧ページからコピー。Google マップ埋め込みの利用規約に留意。
6. **301 リダイレクト**: 旧パーマリンク一覧をサーバー（Netlify / CloudFront / nginx 等）に登録。

## 法務・表記

- 「交通誘導警備シェア鹿児島県No.1」等の訴求は、根拠資料のある表現のみを掲載すること。
- 本リポジトリの成果物は提案・デモ用途の要素を含みます。公開前に貴社で最終監修してください。

# サンプラスワン 単一 HTML 制作仕様（CURSOR_SPEC）

## 目的

- **成果物:** `index.html` **1ファイルのみ**（CSS / JS も同一ファイル内 `<style>` / `<script>` に記述）
- **参考:** [たたき台（Netlify）](https://extraordinary-blini-1bea55.netlify.app/) ・ [旧サイト](https://sunplusone.com/)
- **性质:** デモ／提案用。未確定文言は注記。画像は Unsplash デモ用 URL（本番は差し替え）

## 必須実装（2点）

### 1. 事業内容「フィルムストリップ式スクロールスナップ＋自動スライド」

- 横方向 `overflow-x: auto` + **`scroll-snap-type: x mandatory`**
- 各カード **`scroll-snap-align: center`**（`scroll-snap-stop: always`）
- **自動スライドはON**（ユーザー要望）。**ホバー・フォーカス・スワイプ・ホイールで一時停止**、`prefers-reduced-motion` 時は自動再生を止める
- **矢印カルーセルは不要**（フィルムストリップ表現を維持）
- 各カード: 背景画像 + グラデーション + 業務名 + 概要 + 詳細誘導（同一ページ内アンカーで可）
- 対象業務（6件）: 交通誘導 / 施設 / 機械 / イベント / 列車見張り / 駐車場（旧サイト区分に準拠）

### 2. 右下固定「グラス調バブルドック」

- `position: fixed` + **右下**（`z-index` はオーバーレイより下、スクロール追従）
- **半透明 + `backdrop-filter: blur()`** でガラス風
- **四角一塗りではなく**、「泡」運用: 電話・採用・依頼/問い合わせを **別シルエット**（円 / ひし形寄りの角丸 / 有機的な不等辺の角丸など）で縦に積む
- 依頼カードには **短文 CTA**（例: 「フォームへ →」）

## ブランド／カラー（ロゴ準拠）

- 紺: `#004098` 付近（`--navy`）
- 黄: `#FFD700` 付近（`--gold`）
- 背景・コントラストは可読性優先

## 推奨セクション構成（モダン版）

1. ヘッダー（ロゴ＋グロナビ、同一ページ `#` アンカーで可）
2. 30周年バンド・採用ストリップ（短文・注記あり）
3. **ヒーロー（桜島背景・ガラスモーフィズム）**
   - 左：キャッチコピー＋リード＋CTA（依頼／電話／採用）＋実績スタット3点
   - 右：ガラス調パネルに4枚の現場サムネ（業務ラベル付き）
   - 背景：桜島イメージ（Unsplashのデモ／本番差替）と紺グラデオーバーレイ
4. **フィルムストリップ業務セクション（必須）**＝自動スライド
5. 業務詳細カードグリッド（フィルムストリップから `#detail-*` でジャンプ）
6. フォトギャラリー（グリッド、デモ画像）
7. 採用（写真3点＋見出し＋CTA／仮文案注記）
8. 警備料金（写真＋箇条書き）
9. 事業所紹介（カードリスト）
10. 会社案内（リンクリスト＋写真）
11. アクセス（住所＋写真）
12. お知らせ（カード）
13. お問い合わせ（紺背景フォーム）
14. フッター
15. **グラス調バブルドック（必須）**
16. クイック検索: **左下固定**など、ドックと**重ならない**配置（モバイルでは下ナビ直上を避ける）

セクションは `.sec` / `.sec-alt` で交互背景、各先頭に `.sec-head`（kicker＋title＋lead）で統一感を出す。

## 技術制約

- 外部ライブラリ（React / CDN JS フレームワーク）**不使用**（標準 HTML/CSS/JS のみ）
- 画像は `https://` のみ（許可済みホスト）。OGP や favicon は任意。
- ローカルプレビュー: **`preview.cmd`** はサーバーを別ウィンドウで先に立ち上げ、**約4秒後**に `http://localhost:ポート/` を開く。**3010が埋まっていると 3011→5500→8765 に自動変更**。**127.0.0.1 より localhost の方が繋がる環境があります。** Python 不在時は **`install-python.cmd`**（winget）または python.org。**導入直後はターミナルを閉じ直してから `preview.cmd`**（PATH 更新）。**`verify-env.cmd`** で `py` / `python` / 定番パスを確認。`server-mini.cmd` は PATH に無くても `%LocalAppData%\Programs\Python\Python3xx\python.exe` を試行。`npm run preview`（Node）も可。ロゴは `images/logo.svg`（公式 PNG 入手後に差し替え可）。
